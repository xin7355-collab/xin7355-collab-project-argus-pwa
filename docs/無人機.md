# 🛸 無人機

功能清單「看船・偵蒐 → 🛸 無人機」。一張卡片告訴你**這裡能不能飛、為什麼、找誰申請**，加上起飛前要看的飛行條件。

- 檢查位置：先用我方 GPS，沒有就用畫面中心；**點地圖任何地方就換位置**（卡片上方的地圖看得到禁限航區）
- 地圖上同時畫出禁限航區：紅＝禁止、黃＝有條件（限高、限時、要申請）、綠虛線＝國家公園；
  商港區是點線框，臨時公告（活動、煙火）框線比較粗
- 卡片關掉後圖層還在（🗂️ 圖層可以關）；這時點紅區或黃區會跳出「這裡有哪些公告」

**圖資僅供參考，以民航局及各縣市政府公告為準。** 卡片下方有民航局系統與 GIS 圖台的連結，正式申請也在那裡。

## 結論怎麼看

| 結論 | 意思 |
| --- | --- |
| 🔴 禁止飛航 | 在禁航區、限航區、機場四周禁止範圍、縣市公告的禁止區、商港禁止區，或生效中的臨時公告裡 |
| 🟡 有條件 | 在黃區：例如機場外圍「200 呎（約 61 公尺）以上禁止」，或縣市公告的有條件開放（看說明的時段、限高、誰可以飛） |
| 🟢 另外申請 | 在國家公園內，要向該管理處申請（國家公園法） |
| 🟢 不在公告範圍 | 沒有在任何公告範圍內，但仍要遵守 400 呎、日出到日落、目視範圍等規定 |
| ⚠️ 邊界提醒 | 離某個範圍的邊界不到 50 公尺：手機 GPS 誤差可能讓結果相反，以官方系統為準 |

同一個點在好幾個範圍裡時全部列出來，最重的排前面（民航局公告的機場四周、限航區罰 30–150 萬元，排在縣市公告的前面）。
每一筆都可以點「說明、機關、罰則」看官方原文、主管機關、會商機關（申請時要它同意）。
另外列出「1 公里內」的範圍（延伸視距最遠 900 公尺），以及 30 天內會生效的臨時公告。

## 飛行條件

| 項目 | 資料 | 判斷 |
| --- | --- | --- |
| 法規時段 | 本機天文計算 | 日出到日落才能飛；日落前 30 分鐘提醒收機 |
| 風、降雨、能見度 | Open-Meteo（免金鑰） | 風看地面、80、120 公尺三個高度的最大值（120 公尺的風常比地面大很多）；抗風上限可選 10／12／15 m/s（以機型規格為準） |
| 地磁 Kp | NOAA SWPC | 4 注意、5 以上是磁暴，GPS 與羅盤可能不準 |
| 附近低空有人機 | ADS-B（adsb.lol） | 5 浬內、3000 呎以下；2 浬內有就紅燈。沒裝 ADS-B 或沒被收到的飛機不會出現 |
| GPS 干擾 | 飛機回報的定位精度（推估） | 按一下開 📵 圖層看 |

逐時天氣列出接下來 6 小時；日落後的時段標 🌙（法規不能飛，不給綠燈）。

## 法規重點（卡片裡的「📜 法規重點」有條號）

- 距地面或水面不得超過 **400 呎（約 120 公尺）**；**日落後到日出前不得飛航**；在**目視範圍內**操作（民用航空法第 99 條之 14）
- **不得在移動中的船艦上操作**（遙控無人機管理規則第 28 條第 1 項第 2 款）；政府機關（構）依第 32 條向民航局申請許可後不受此限
- 禁限航區、機場四周：政府機關（構）執行業務要申請民航局會商同意，活動日 15 天前申請（涉及軍事管理 30 天前）
- 政府機關執行災害防救、偵查、調查、矯正等法定職務，經民航局同意可排除部分限制（第 99 條之 16）
- 商港區：只有政府機關（構）、學校、法人為公務等需要可以申請，飛航 7 天前向港務公司或航港局申請
- 罰則：禁限航區、機場四周、超過 400 呎 → 30 萬到 150 萬元、廢止操作證、得沒入（第 118 條之 1）

條文摘自全國法規資料庫（民用航空法 2023-06-28、遙控無人機管理規則 2024-11-14、
商港區域特定範圍內遙控無人機飛航活動申請及管理辦法 2026-02-09 修正版），以官方最新條文為準。

## 資料從哪裡來、多久更新

- 民航局「遙控無人機管理資訊系統」GIS 圖台背後的圖層：主空域（禁限航區、機場四周、縣市公告，約 5,000 筆）、
  臨時空域、商港區、國家公園。民航局沒有提供下載檔，這些是圖台公開使用的查詢端點（不是正式文件化的 API，
  欄位哪天變了同步會失敗、會紅燈，不會默默給錯的資料）
- GitHub Actions「無人機禁限航區資料」每天台灣時間 01:23 同步：先直連民航局，連不到就改用 GitHub 上的每日鏡像
  （TonyPepeBear/taiwan-drone-caa-data，同一批圖層）。資料有變才更新並重新部署
- **聯絡方式整欄不收**：民航局資料裡有承辦人姓名、手機、Email，本 repo 公開，不轉載；
  要聯絡時到民航局系統用機構帳號查
- 手機只下載看得到的那幾格（市區一格壓縮後約 50–100 KB）；**看過的地方沒訊號也查得到**
- 縮小看全台時只畫機場、限航區、商港、國家公園；放大到約 30 公里寬才畫縣市公告的幾千筆小範圍

## 給維護的人

- 判定與資料格式：`src/lib/droneZones.ts`（App、同步腳本共用，可離線測）；讀圖磚：`src/lib/droneClient.ts`；
  飛行條件：`src/lib/droneConditions.ts`；畫面：`src/components/DronePanel.tsx`、`src/map/DroneZoneLayer.tsx`
- 同步：`node --experimental-strip-types scripts/drone-zones.mjs build --out <資料夾>`；
  離線自我測試：`node --experimental-strip-types scripts/drone-zones.mjs selftest`
- 資料放在 Release「drone-zones」的附件（不進 git 歷史），部署時解開放進 `dist/drone/`
- 外部來源實測：Actions「探測無人機資料來源」（`scripts/probe-drone.mjs`）
