# 🎙️ 語音助理

用說的（或打字）問，例如：

- 「基隆港到彭佳嶼多遠？」
- 「今晚這裡幾點完全天黑？月亮多亮？」（要勾「附上目前地圖中心」）
- 「附近有沒有發緊急代碼的飛機？」（要勾「附上目前地圖中心」）
- 「我 20 節，目標在 25.2, 121.9 往 270 度 10 節，怎麼攔？」

**數字都是 App 自己的公式算的**（跟 MCP 連接器同一套工具），AI 只負責聽懂要算什麼、把結果講成一句話。
回答會用中文念出來（右上角 🔊／🔇 切換）。

## 設定（約 10 分鐘，用免費的 Groq）

1. 到 <https://console.groq.com/keys> 登入（可用 Google 帳號）→ **Create API Key** → 複製（只顯示一次）
2. 開 <https://github.com/xin7355-collab/xin7355-collab-project-argus-pwa/settings/secrets/actions>
   → **New repository secret**：名稱 `GROQ_API_KEY`，內容貼剛剛那串
3. App 的 **⚙️ 設定 → 🎙️ 語音助理 → 產生**（會自動複製）→ 回 GitHub 再新增 secret：
   名稱 `AI_ACCESS_TOKEN`，內容貼那串 → 回 App 按「儲存並套用」
4. 開 <https://github.com/xin7355-collab/xin7355-collab-project-argus-pwa/actions/workflows/deploy.yml>
   → **Run workflow**（部署時會把金鑰送到伺服器；之後改了 secret 也要再跑一次）
5. 功能清單 →「🎙️ 語音助理」

### 選用

- `GEMINI_API_KEY`：<https://aistudio.google.com/apikey>，免費，當 Groq 用完額度時的備援
- `OPENROUTER_API_KEY`：只會用它的免費模型
- `ANTHROPIC_API_KEY`（Claude）：**付費**。加之前先到 Claude 的開發者後台
  （<https://platform.claude.com>，帳單／Limits 設定）設每月預算上限。
  順序永遠是免費的先用，都不行才用付費的

## 隱私

- 你說的話會送到 AI 供應商處理；勾「附上目前地圖中心」時，地圖中心座標也會送出（預設不勾）
- 免費方案可能被拿去改進服務：Google 的 Gemini API 條款寫明免費層的內容可能用來改進產品、
  可能有人工審閱，也建議不要送敏感資料。**機敏的位置、船名不要說**
- 金鑰只在伺服器（Cloudflare Worker 的 secret），手機和網頁都拿不到；
  通行碼擋的是「別人拿你的網址用掉你的額度」

## 語音輸入

- 有 🎙️ 按鈕時：按一下開始說，說完自動送出
- 沒有按鈕、或說「沒有權限」：點輸入框，用**鍵盤上的麥克風（聽寫）**，一樣可以
- iPhone 權限：設定 → Safari → 麥克風 → 允許

## 燈號／訊息怎麼看

| 訊息 | 意思 | 怎麼做 |
| --- | --- | --- |
| ⚪ 還沒設定 | App 沒有通行碼，或伺服器還沒有金鑰／通行碼 | 照上面步驟；改完 secret 要重跑部署 |
| 🔴 通行碼不對 | App 的通行碼跟 GitHub 的 `AI_ACCESS_TOKEN` 不一樣 | 重新複製貼上；改過 secret 要重跑部署 |
| 🟡 問得太快 | 每分鐘最多 20 次 | 等 1 分鐘 |
| 🔴 AI 暫時用不了 | 各家都失敗（多半是免費額度用完） | 稍後再試；可以多加一家當備援 |

## 技術細節（給維護的人）

- 前端 `src/components/AssistantPanel.tsx`；問答流程 `src/lib/assistant.ts`（App 與 Worker 共用、可離線測）；
  伺服器 `worker/ai.js`（`/api/ai`）
- AI 呼叫一律走 skl 的 **ai-model-router**（`worker/vendor/model_router.cjs`，原樣複製）：只寫等級 `fast`，
  不寫死模型名稱；模型下架自動換、回覆格式不對自動升級到更強的模型、付費的逾時不重送。
  它的自我測試跟著 `npm test` 跑（`src/lib/modelRouter.test.ts`）
- 不用各家的原生「工具呼叫」格式（每家都不同），而是要求 AI 只回一段 JSON：
  `{"tool": …, "arguments": …}` 或 `{"answer": …}`；一次問題最多用 3 次工具
- 更新路由模組：從 skl 的 `xin-toolkit/skills/ai-model-router/assets/` 複製 `model_router.js`（改名 `.cjs`）
  與 `router_cases.json` 蓋掉 `worker/vendor/` 裡的，跑 `npm test`
