# 操作說明（v2.41 改版後）

打開就是一張完整的地圖。所有功能都在**底部抽屜**裡。

```
┌──────────────────────────────┐
│ 🔍 搜尋地名、港口，或輸入座標    ⚙️ │ ← 搜尋列（座標不用連網）
│ ◎ 24.5000N 122.0000E · z7       │ ← 畫面中心座標
│                               │
│            地  圖              │
│                         [🗺️]  │ ← 地圖類型（地圖／衛星／海圖／夜間）
│                         [📍]  │ ← 我的位置（長按＝記錄航跡）
├──────────── ═══ ─────────────┤ ← 把手：拖、或點一下
│ ⚡掃描  🚢AIS  🌤️影像  🆘漂流  🌊海況 │ ← 最常用的五個
└──────────────────────────────┘
```

## 底部抽屜

- **往上拉**（或點一下把手）→ 看到全部功能，依用途分組
- **往下拉** → 收起來，地圖幾乎全看得到
- 點一下把手：收起 → 一半 → 全開 → 一半…

選了一個功能（例如 AIS）之後，抽屜上方會顯示它的名稱和 **✕ 結束**。
按 **✕ 結束** 就回到地圖。

## 地圖類型（右下 🗺️）

| 類型 | 適合 | 備註 |
| --- | --- | --- |
| 🗺️ 地圖 | 平常用、找地名港口 | 台灣範圍是**中文**，可放大到門牌等級 |
| 🛰️ 衛星 | 看海岸、港區、碼頭 | 放大後疊**中文路名地名**；外海用無雲衛星補 |
| ⚓ 海圖 | 看水深地形、燈塔浮標 | 水深資料只到中等比例，**放大會變糊** |
| 🌙 夜間 | 夜航、駕駛台上 | 暗色不刺眼，細節較少 |

> 這些都是**鑲嵌圖或向量地圖，不是今天拍的**。要看特定日期的海上影像，
> 用「🌤️ 衛星影像」功能選日期。

### 為什麼放大後有些地方是一片海藍色？

免費圖資在「沒有資料」的地方（外海、或某些地區的高倍率），伺服器不會說「沒有」，
而是回一張假圖——灰底寫著「Map data not yet available」，或一整片淺藍。
App 會自動認出這些假圖藏起來，露出底下有資料的那一層；真的每一層都沒有，
就露出海的顏色。這是故意的，比滿畫面的灰色字塊好讀。

## 搜尋列

- **座標**：直接輸入就飛過去，不用連網。格式很寬鬆：
  `25.13, 121.74`、`25°07.9'N 121°44.5'E`、`N25 07.9 E121 44.5` 都可以
- **地名**：需要連網（OpenStreetMap）。按鍵盤上的「搜尋」才會查
- 搜尋到的點是**暫時的**，要保留請在點位上按「釘選」或「存成點位」

## 其他

- **比例尺**在左下，單位跟著 ⚙️ 設定的距離單位（預設浬）
- **狀態提示**會在抽屜上方浮出，幾秒後自己收起；點一下立刻收起
- **離線地圖**：下載的是「目前選的地圖類型」。出海前先切到要用的類型再下載
