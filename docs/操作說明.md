# 操作說明（v2.41 改版後）

打開就是一張完整的地圖。所有功能都在**底部抽屜**裡。

```
┌──────────────────────────────┐
│ 🔍 搜尋地名、港口，或輸入座標    ⚙️ │ ← 搜尋列（座標不用連網）
│ ◎ 24.5000N 122.0000E · z7       │ ← 畫面中心座標
│                               │
│            地  圖              │
│                         [🗺️]  │ ← 地圖類型（地圖／衛星／海圖／夜間）
│                         [📍]  │ ← 我的位置（長按＝記錄航跡）
├──────────── ═══ ─────────────┤ ← 把手：拖、或點一下
│ ⚡掃描  🚢AIS  🌤️影像  🆘漂流  🌊海況 │ ← 最常用的五個
└──────────────────────────────┘
```

## 底部抽屜

- **往上拉**（或點一下把手）→ 看到全部功能，依用途分組
- **往下拉** → 收起來，地圖幾乎全看得到。清單已經捲到最上面時，
  在清單上往下拉也可以（不用特地去抓把手）；清單還沒到頂時往下拉是捲清單
- 點一下把手：收起 → 一半 → 全開 → 一半…

選了一個功能（例如 AIS）之後，抽屜上方會顯示它的名稱和 **✕ 結束**。
按 **✕ 結束** 就回到地圖。

## 地圖類型（右下 🗺️）

| 類型 | 適合 | 備註 |
| --- | --- | --- |
| 🗺️ 地圖 | 平常用、找地名港口 | 台灣範圍是**中文**，可放大到門牌等級 |
| 🛰️ 衛星 | 看海岸、港區、碼頭 | 放大後疊**中文路名地名**；外海用無雲衛星補 |
| ⚓ 海圖 | 看水深地形、燈塔浮標 | 水深資料只到中等比例，**放大會變糊** |
| 🌙 夜間 | 夜航、駕駛台上 | 暗色不刺眼，細節較少 |

> 這些都是**鑲嵌圖或向量地圖，不是今天拍的**。要看特定日期的海上影像，
> 用「🌤️ 衛星影像」功能選日期。

### 為什麼放大後有些地方是一片海藍色？

免費圖資在「沒有資料」的地方（外海、或某些地區的高倍率），伺服器不會說「沒有」，
而是回一張假圖——灰底寫著「Map data not yet available」，或一整片淺藍。
App 會自動認出這些假圖藏起來，露出底下有資料的那一層；真的每一層都沒有，
就露出海的顏色。這是故意的，比滿畫面的灰色字塊好讀。

## 搜尋列

- **座標**：直接輸入就飛過去，不用連網。格式很寬鬆：
  `25.13, 121.74`、`25°07.9'N 121°44.5'E`、`N25 07.9 E121 44.5` 都可以
- **船名／MMSI**：邊打字邊列出手機上已收到的 AIS 船（不用連網）。點一下就切到 AIS、
  飛過去並打開那艘船的資料；打完整 MMSI 按「搜尋」也會直接過去。
  不在 AIS 模式時列出的是「上次 AIS 收到的」船位
- **地名**：需要連網（OpenStreetMap）。按鍵盤上的「搜尋」才會查。
  主要查 Nominatim，它忙或找不到時自動改查 Photon（打錯字也常找得到）；
  查過的地名 5 分鐘內不用再連網
- 搜尋到的點是**暫時的**，要保留請在點位上按「釘選」或「存成點位」

## 分享給同事

- **分享畫面**（功能清單 → 定位・量測 → 🔗）：把目前位置、模式、地圖類型變成一個連結，
  iPhone 會跳出分享選單（LINE、訊息…）；不支援的話會複製到剪貼簿
- **分享一艘船**：點船 → **🔗 分享**。對方打開連結會進 AIS、飛到那裡，
  那艘船一回報就自動打開它的資料。3 分鐘內都沒回報會告訴對方（可能駛離、關了 AIS）
- 連結裡只有座標、模式、MMSI，看得懂、不含金鑰。位置在網址 # 後面，不會送到伺服器
- 連結被截斷或改壞時，App 會說「看不懂」並忽略，不會只套一半

## 飛機與 GPS 干擾（✈️ 飛機、📵 GPS 干擾）

功能清單上「✈️ 飛機」「📵 GPS 干擾」是開關：按一下打開（格子亮綠框、標「開」），再按一下關掉。
也可以在 🗂️ 圖層 → ✈️ 空中 打勾，下面的燈號會說抓到幾架、有沒有出問題。

- **資料來源**：adsb.lol（免金鑰，資料授權 ODbL，地圖右下會註明）。經過我們自己的 Worker 轉手，
  手機只收需要的欄位；12 秒內同一片海域的請求共用一份
- **飛機顏色**：紅色閃爍＝發緊急代碼（7700 一般緊急、7600 無線電失效、7500 劫機）、
  橘＝軍機（adsb.lol 資料庫標記）、綠＝直升機（常是搜救、海巡）、白＝一般、灰＝在地面。
  有飛機發緊急時會跳一次提示
- **看不到飛機不代表天上沒有**：adsb.lol 靠地面的志工接收站，遠離陸地的外海常收不到
- **GPS 干擾是推估**：飛機會廣播自己的定位精度。同一格（0.5°，約 30 浬）裡很多飛機都回報精度變差，
  就標成「定位異常」：黃＝2–10% 的飛機變差、紅＝超過 10%（照 gpsjam.org 的算法，先扣掉一架避免誤報；
  每格至少 3 架飛機才判斷，看最近 30 分鐘）。可能原因是 GPS 干擾或欺騙，但個別飛機的航電問題也會造成，
  所以是「可能」，不是「確定」。這是高空飛機看到的情況，海面上的船受影響的範圍可能不同
- 打開越久、看過的海域越多，格子越完整（開著才會累積，關掉 App 就重來）
- adsb.lol 忙或連不上時，會拿最近一份資料頂著並亮黃燈；飛機位置超過 2 分鐘沒更新就收掉（會誤導）
- 手機、桌機都能用

## 放大字、減少動畫

- 可以用**兩指放大整個畫面**（以前被鎖住）。地圖上兩指仍是縮放地圖
- iPhone「設定 → 輔助使用 → 動態效果 → 減少動態效果」打開時，
  地圖不再「飛」過去，直接跳到目的地；抽屜、按鈕也不做動畫

## 圖層的燈號（🗂️ 圖層）

打勾的圖層下面會多一行，告訴你這份資料現在的狀況：

| 燈號 | 意思 |
| --- | --- |
| ⏳ 載入中 | 正在抓 |
| 🟢 正常 | 抓到了，後面寫抓到多少 |
| ⚪ 這裡沒有資料 | 抓成功，但這一帶真的沒有（例如 OSM 沒標電纜） |
| 🟡 改用備援 | 抓不到，先顯示內建的示意範圍 |
| 🟡 資料不新／部分 | 只抓到一部分，沒上色的格子不代表沒事 |
| 🔴 抓不到 | 伺服器忙或連不上，後面寫原因；**這不代表沒有**（沒風、沒雨、能見度好都不能這樣推） |

以前好幾個圖層抓失敗時跟「沒資料」長得一樣，能見度甚至會說「大致良好」、風場會畫一整片假箭頭——現在都改成紅燈講清楚。
