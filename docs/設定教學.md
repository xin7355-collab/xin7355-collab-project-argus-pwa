# 設定教學（手機可完成）

三件事要設定，分開做、互不影響：

- **A. Sentinel 金鑰** — 讓掃描真的看得到「今天的船」，也讓「雷達暗船」能用。**最值得先做。**
- **B. 盯梢推播** — 你關注的海域一有新衛星影像就推到手機。
- **C. AIS 金鑰與連線診斷** — 看即時船位；看不到船時怎麼查。

---

## A. Sentinel 金鑰（免費，約 10 分鐘）

### 為什麼要做

目前免金鑰能用的最高解析度影像是 **Esri 高解析空拍**，它沿岸可以到次公尺級，很清楚 —— 但它是**歷年鑲嵌圖**，不是今天。

| 來源 | 看得到小艇 | 是今天 |
| --- | --- | --- |
| Esri 高解析（免金鑰） | ✅ 次公尺 | ❌ 歷年鑲嵌 |
| **Sentinel-2（本頁要申請的）** | ✅ 10m | ⚠️ 約 5 天過境一次 |
| VIIRS / MODIS（免金鑰） | ❌ 250–375m | ✅ 每天 |

**免費衛星沒有「每日又超清」的。** Sentinel 是唯一能同時逼近兩者的免費選項。

沒有這把金鑰，「⚡ 一鍵掃描」掃的是歷年鑲嵌圖 —— 它會抓到東西，但那些是固定設施和地形，不是今天的船。

### 步驟

**1. 註冊 Copernicus 帳號（免費）**

開 <https://dataspace.copernicus.eu/>

右上角 **Register** → 填 email 和密碼 → 去信箱收驗證信 → 點驗證連結。

> 帳號完全免費，不用信用卡。

> ⚠️ **不要用 insights.planet.com**：那是 Planet 公司的商業平台，註冊後是「30 天試用、會到期」，
> 它給的 Instance ID 跟免費的 CDSE 不通用。本 App 預設用的是免費、不到期的 CDSE。

**2. 進 Sentinel Hub Dashboard**

開 <https://shapps.dataspace.copernicus.eu/dashboard/#/> ，用剛註冊的帳號登入。

> 這個網址是官方說明頁上的連結（2026-10 讀過）；我沒辦法實際登入點過。

**3. 找一個 configuration，複製 Instance ID**

左側面板 → **Configuration Utility**。帳號本來就有一個 **Simple WMS Instance** 可以直接用；
也可以按 **New Configuration** 自己建一個（名字隨便取，例如 `argus`）。

每個 configuration 都會有一串 **Instance ID**，長得像：

```
12345678-abcd-1234-abcd-1234567890ab
```

複製它。

**4. 貼進 App**

開 <https://argus-app.xin7355.workers.dev>

右上角 **⚙️ 設定** → 找到 **Sentinel Instance ID** 欄位 → 貼上 → **儲存並套用**。

> WMS 網址保持預設的 **✅ 免費 CDSE（Copernicus）** 就好，不要改成
> 「💳 Planet/商業」那個。

**4b. 加雷達圖層（要用「雷達暗船」才需要）**

App 會自己讀你組態裡有哪些圖層、挑出光學與雷達要用的那個，名字不用一字不差。
但 Sentinel-2 為主的組態**本來就沒有雷達圖層**，這時 ⚙️ 設定和 AIS 面板的「雷達暗船」底下
會直接說「組態裡沒有雷達圖層（現有：…）」，照這樣加：

1. 同一個儀表板 → 左側 **Configuration Utility** → 點你在用的那個組態
2. 按 **New Layer**
3. **Name** 填 `SAR-VV`
4. **Source** 選 **Sentinel-1 GRD**
5. **Data Processing** 按鉛筆圖示，從內建的選一個 **VV**、**decibel**（分貝）的
6. 存檔 → 回 App 按「🔄 改好了，重新檢查」

> 查證範圍：網址、`Configuration Utility`、`New Layer`、`Name`／`Source`、
> 「鉛筆圖示可選內建處理方式」、「Configuration Utility 有內建分貝輸出的 S1GRD 處理方式」
> 都是官方說明寫的（QGIS 與 S1GRD 說明頁）。**沒驗到**：Source 選單裡的確切字樣
> （可能寫 `Sentinel-1 GRD` 或 `S1GRD`）、內建處理方式的確切名稱、存檔鈕叫什麼——
> 我沒辦法實際登入點過，畫面不一樣就挑意思最接近的。

**5. 確認生效**

存檔後**不會重新整理頁面**（地圖位置和模式都會留著）。往下看「🔑 金鑰解鎖狀態」那張卡，
`Sentinel 金鑰` 那一列應該從 🔒 變成 🔓。

⚙️ 設定的 Instance ID 欄位下面會出現檢查結果：

| 看到 | 意思 |
|---|---|
| ✅ 組態檢查通過：光學用「…」、雷達用「…」 | 都好了 |
| ⚠ 組態裡沒有雷達／光學圖層（現有：…） | 照上面 4b 加 |
| Copernicus 說這個 Instance ID 不存在 | 重新複製貼上；確認 WMS 網址是「免費 CDSE」 |
| 連不到 Copernicus 檢查組態 | 網路問題，先照預設名稱載入，晚點再按重新檢查 |

接著：切到 **🌤️ 沿岸光學** 模式，面板上方會從
「免金鑰：地圖顯示該日 MODIS（250m…）」變成
「✅ 有 Sentinel 金鑰：…Sentinel-2（10m）真實影像」。

這時候再按 **⚡ 一鍵掃描**，掃的才是真正的當日影像。

## B. 盯梢推播（約 5 分鐘）

### 這會做什麼

每 6 小時自動查一次 Copernicus 目錄，**你關注的海域一有新的 Sentinel 影像就推播到手機**，
你就不用每天開 App 碰運氣。

### ⚠️ 先知道：這個 repo 是公開的

所以設計上刻意做了三件事：

- 監控範圍放 **GitHub Secret**，不寫進程式碼（座標進公開 repo = 公開你在盯哪裡）
- 推播內容**不帶座標、不帶影像編號**（Sentinel 的影像編號本身就編碼地理位置）
- **完全不存紀錄**（存「上次看到什麼」同樣會洩漏範圍）

推播只會說「有幾筆、哪個感測器、多久以前、最少雲幾 %」，細節回 App 看。

### 步驟

**1. 裝 ntfy**

App Store 搜尋 **ntfy** → 安裝。不用註冊、不用登入。

**2. 想一個主題名**

這個名字**等同通行證** —— 誰知道它誰就收得到你的通知。所以**不要用 `argus` 這種好猜的**。

建議：英數字混 20 字元以上，例如

```
argus-k7m2x9p4qw8vn3zr
```

先記在手機備忘錄裡，等一下兩個地方都要用同一個。

**3. 在 ntfy App 裡訂閱**

ntfy App → 右下角 **＋** → 貼上剛才那個主題名 → **Subscribe**。

**4. 設兩個 GitHub Secret**

開 <https://github.com/xin7355-collab/xin7355-collab-project-argus-pwa/settings/secrets/actions>

按 **New repository secret**，加兩個：

| Name | Secret |
| --- | --- |
| `NTFY_TOPIC` | 剛才那個主題名 |
| `WATCH_BBOX` | 你要盯的範圍，見下 |

`WATCH_BBOX` 格式是 **`西,南,東,北`**（四個數字，逗號分隔，不要空格）。

台灣東部海域大致可用：

```
121.0,23.5,123.0,25.5
```

想自己調：在 App 裡把地圖移到要盯的範圍，左上角會顯示中心座標，
以它為中心抓一個方框就行。範圍不用太精確，寧可大一點。

**5. 先測試，再相信它**

開 <https://github.com/xin7355-collab/xin7355-collab-project-argus-pwa/actions>

左側點 **盯梢新衛星影像** → 右邊 **Run workflow** →
**`self_test` 打勾** → 按綠色的 **Run workflow**。

約一分鐘後手機應該收到一則：

> 阿爾戈斯：通知管線測試
> 收到這則就表示排程盯梢設定成功了。

**收到 = 全部設定正確。** 之後每 6 小時它會自己跑。

**沒收到**，依序檢查：

1. ntfy App 裡訂閱的主題名，跟 `NTFY_TOPIC` 這個 Secret 是不是**一模一樣**（大小寫也要一樣）
2. Actions 那一頁，這次執行是綠燈還是紅燈 —— 紅燈的話點進去看錯誤訊息，它會直接講缺什麼
3. iPhone 的「設定 → 通知 → ntfy」有沒有允許通知

## C. AIS 金鑰與連線診斷

### 金鑰

到 <https://aisstream.io> 登入 → **API Keys** → 複製 → 貼到 App 的
**⚙️ 設定 → AISStream 金鑰** → 儲存並套用。

### 看不到船時

進 🚢 AIS 船位，有金鑰但還沒有船時，面板上會有 **🩺 連線診斷** 卡片，直接寫出卡在哪：

| 診斷 | 意思 | 怎麼辦 |
|---|---|---|
| 每次一連上就被切斷 | 金鑰幾乎確定無效 | 到 aisstream.io 重新複製金鑰 |
| 連線是通的，但一直沒有船位 | 這片海附近沒有 aisstream 的接收站（它靠志工架站） | 按「測試金鑰」確認；移到別的海域看看 |
| 兩條路線都連不上 | 網路或 aisstream 停機 | 換 Wi-Fi／行動網路，稍後再試 |

**🔑 測試金鑰**：暫時改訂閱英吉利海峽（全球 AIS 最密集的地方）15 秒。
收得到＝金鑰沒問題；收不到＝金鑰的問題。測完自動回到原本的海域。

### App 裡判不出來時：用 GitHub 伺服器幫你測

App 說「一連上就被切斷」，有可能是金鑰真的壞，也可能是 aisstream 擋瀏覽器。
從手機分不出來，可以請 GitHub 的伺服器用同一把金鑰測四種情況：

1. 開 <https://github.com/xin7355-collab/xin7355-collab-project-argus-pwa/settings/secrets/actions/new>
2. **Name** 填 `AISSTREAM_KEY`，**Secret** 貼 aisstream 的金鑰 → **Add secret**
3. 開 <https://github.com/xin7355-collab/xin7355-collab-project-argus-pwa/actions/workflows/ais-key-check.yml>
   → **Run workflow** → 再按一次綠色 **Run workflow**
4. 約 2 分鐘後點進去看「Summary」，結論會寫：金鑰有效／金鑰無效／aisstream 擋瀏覽器／本站轉接不通／台灣沒資料

紀錄只印數量和斷線碼，不印金鑰也不印船位（這個 repo 是公開的，紀錄大家看得到；
GitHub 也會自動遮掉 Secret）。

App 有兩條路連 aisstream：先走本站轉接（Cloudflare Worker），被切斷兩次就自動改直連，
哪條收得到資料就一直用哪條。點「最近幾次連線紀錄」可以看到每次走哪條、連多久、收到幾筆。

## 常見問題

**Q：兩個都一定要設嗎？**
不用。A 和 B 完全獨立。只做 A 也行（App 的掃描會變準），只做 B 也行（會通知但你還是看 250m 影像）。
**建議先做 A**，那個對日常使用的影響比較大。

**Q：Sentinel 金鑰會不會收費？**
CDSE 帳號本身免費。免費額度有每月上限，這個 App 的用量（看圖磚）遠低於上限。
> 沒驗到：額度的確切數字我沒有查證到可靠的現行值，不在這裡列數字誤導你。

**Q：ntfy 的主題名被別人知道會怎樣？**
他會收到你的通知。但通知內容本身不含座標和影像編號，所以外洩的只有「有新影像」這件事。
真的介意就換一個主題名（兩個地方一起改）。

**Q：盯梢會不會一直吵我？**
不會。Sentinel 幾天才過境一次，沒有新影像就完全不發通知。
